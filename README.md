# Python Fundamentals 🐍

Welcome to my **Python Fundamentals** repository! This repo documents my day-by-day journey of learning Python, tracking the concepts, syntax, and built-in functions I have studied.

---

## 📅 Learning Log

### **Day 1: Python Basics**
My first day focused on the foundational building blocks of Python.
* **Variables:** Naming conventions, assigning values, and dynamic typing.
* **Data Types:** Working with the core types like `int`, `float`, `str`, and `bool`.
* **Functions:** How to define reusable blocks of code using the `def` keyword, passing arguments, and returning values.
* **Methods:** Understanding the difference between standalone functions and object-specific methods.

### **Day 2: String Manipulations**
Day two was all about handling text and text formatting.
* **String Operations:** Concatenation, repetition, and basic string manipulation.
* **F-Strings:** Using formatted string literals (`f"..."`) for clean and readable variable interpolation.
* **Slicing & Indexing:** Accessing specific characters (`text[0]`) and extracting substrings (`text[start:stop:step]`).
* **Cleaning:** Removing unwanted whitespace or characters using methods like `.strip()`, `.lstrip()`, and `.rstrip()`.
* **Search:** Locating substrings using `.find()`, `.index()`, and checking conditions with `.startswith()` and `.endswith()`.

### **Day 3: Numbers and Lists**
Day three shifted focus to mathematical operations and data structures.
* **Numeric Operations & Operators:** Arithmetic operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`), comparison operators, and assignment operators.
* **Rounding & Math:** 
  * Using the built-in `round()` function.
  * Utilizing the `math` module for `math.ceil()` (rounding up) and `math.floor()` (rounding down).
* **List Operations:** Creating lists, indexing, slicing, and modifying lists using methods like `.append()`, `.insert()`, `.remove()`, and `.pop()`.
